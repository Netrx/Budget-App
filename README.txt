МОБИЛЬНОЕ ПРИЛОЖЕНИЕ «МОЙ БЮДЖЕТ» — ОБНОВЛЁННАЯ ВЕРСИЯ

Добавлено:
- безопасное удаление категорий без повреждения старых операций;
- отдельные категории доходов;
- графики доходов и расходов по категориям;
- статистика дашборда за всё время, текущий месяц, текущий год или произвольный период;
- одновременный выбор нескольких категорий в отчётах;
- полная резервная копия и перенос данных между устройствами;
- фотографии для каждой операции дохода или расхода.

ОБНОВЛЕНИЕ НА GITHUB PAGES
1. Распакуйте архив.
2. Загрузите все файлы из папки budget_mobile_app в корень существующего репозитория с заменой старых.
3. Выполните Commit changes.
4. Дождитесь зелёной отметки в Actions.
5. Откройте приложение и обновите страницу. При необходимости удалите старую установленную PWA и установите заново.

ПЕРЕНОС ДАННЫХ
На старом устройстве: Настройки → Скачать полную резервную копию.
Передайте JSON-файл на другое устройство.
На новом устройстве: Настройки → Импортировать резервную копию.
Импорт заменяет текущие данные и восстанавливает операции, категории и фотографии.
