МОБИЛЬНОЕ ПРИЛОЖЕНИЕ «МОЙ БЮДЖЕТ»

Файлы готовы для размещения на GitHub Pages.

1. Создайте новый публичный репозиторий на GitHub.
2. Загрузите в корень репозитория файлы:
   index.html
   styles.css
   app.js
   manifest.webmanifest
   sw.js
   icon.svg
3. Откройте Settings → Pages.
4. В Source выберите Deploy from a branch.
5. Выберите ветку main и папку /(root), затем Save.
6. GitHub выдаст ссылку вида https://имя.github.io/название-репозитория/

Приложение хранит данные локально в браузере телефона. Для переноса данных используйте Экспорт JSON и Импорт JSON.
